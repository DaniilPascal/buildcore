# Техническое задание — BuildCore (вариант 1)

## Назначение

Веб-приложение для подбора комплектующих персонального компьютера.
Пользователь выбирает детали, собирает конфигурацию, регистрируется и сохраняет заявку.

## База данных (ПР 3)

СУБД: SQLite. Не более двух таблиц.

### users
- id, name, email, password (SHA-256), created_at

### orders
- id, user_id → users.id, phone, comment, items_json, total, created_at

## API

| Метод | Путь | Назначение |
|---|---|---|
| POST | `/api/register` | регистрация |
| POST | `/api/login` | вход |
| GET | `/api/users` | список пользователей |
| POST | `/api/orders` | сохранить заявку |
| GET | `/api/orders` | список заявок |
| GET | `/api/health` | проверка живости сервиса |

## Этапы

### ПР 1
Навигация, адаптив, статический контент.

### ПР 2
Фильтры, сборка в localStorage, формы, внешние API.

### ПР 3
FastAPI + SQLite, серверная авторизация и заявки.

### ПР 4
Docker-образ, публикация репозитория, работающий HTTPS-адрес в интернете.
Конфигурация постоянного хостинга: `Dockerfile`, `docker-compose.yml`, `render.yaml`.
